```python
# Imports
import torch

import warnings

```

The class below implements a Transformer model for sequence learning using PyTorch.
#### Parameters
- `vocab_size` = Vocabulary
- `embedding_dim` = input embedding dimension
- `n_heads` = number of attention heads
- `n_layers` = number of layers
- `dropout` = whether dropout will be used or not  
  It is a regularization strategy used to avoid overfitting.

```python
# Class
class Transformer(nn.Module):

    # Constructor method
    def __init__(self, vocab_size, embedding_dim, n_heads, n_layers, dropout):

        # Initializes the constructor of the parent class (nn.Module)
        super().__init__()

        # Initializes attributes
        self.vocab_size = vocab_size
        self.embedding_dim = embedding_dim
        self.n_heads = n_heads
        self.n_layers = n_layers
        self.dropout = dropout
        
        # Defines the embedding layer that will transform the input sequence
        # into a sequence of fixed-size vectors
        self.embedding = nn.Embedding(vocab_size, embedding_dim)

        # Defines the multi-head self-attention mechanism
        self.attention = nn.MultiheadAttention(embedding_dim, n_heads, dropout=dropout)

        # Defines the feed-forward neural network that will be used to generate
        # the output sequence from the input sequence
        self.feed_forward = nn.Sequential(
            nn.Linear(embedding_dim, embedding_dim),
            nn.ReLU(),
            nn.Linear(embedding_dim, embedding_dim)
        )

        # Defines the final output layer that will transform the output sequence
        # into the desired output format
        self.out = nn.Linear(embedding_dim, vocab_size)

    # Forward method
    def forward(self, x):
    
        # Applies the embedding layer to the input sequence
        x = self.embedding(x)
        
        # Applies the multi-head self-attention mechanism
        x = self.attention(x)
        
        # Applies the feed-forward method
        x = self.feed_forward(x)

        # Applies the final layer
        x = self.out(x)
        
        return x
```

To create a Transformer model, you can instantiate the `Transformer` class and specify the model hyperparameters, such as the vocabulary size, embedding dimension, number of attention heads, number of layers, and dropout rate.

## Building a Transformer Model Without Using a Framework

I will create a model capable of predicting sequences with a length equal to 10 tokens.

A Transformer model consists of several main parts:
- 1 — Embedding Layer: Transforms words into fixed-size numerical vectors.
- 2 — Attention Mechanism: Allows the model to focus on different parts of the input.
- 3 — Encoder and Decoder Layers: Process the data sequentially.
- 4 — Linear Layer and Softmax: Used for final predictions.

For this project, the main objective is to implement item 2, but to make the example functional, I will also implement items 1 and 4.

## Embedding Layer

The embedding function is used to convert sequential inputs into dense fixed-size vectors.

These vectors are known as embeddings and are a fundamental part, especially in NLP models.

These embeddings are essential for deep learning models in NLP because they provide a rich and dense representation of words or tokens, capturing contextual and semantic information that is essential for tasks such as machine translation, text classification, among others.

```python
# Defines the function to create an embedding matrix
def embedding(input, vocab_size, dim_model):

    # Creates an embedding matrix where each row represents a token from the vocabulary
    # The matrix is initialized with normally distributed random values
    embed = np.random.randn(vocab_size, dim_model)

    # For each token index in the input, selects the corresponding embedding from the matrix
    # Returns an array of embeddings corresponding to the input sequence
    return np.array([embed[i] for i in input])
```
## Attention Mechanism

In this example, I will simplify and use only one attention layer.
In the Transformer, Q, K, and V are derived from the same input in the encoder attention layers, but from different inputs in the decoder.
Q comes from the output of the previous decoder layer, while K and V come from the encoder output.
The attention mechanism calculates a set of scores using the dot product between Q and K, hence the name **scaled dot-product attention**.
It then applies a softmax function to obtain attention weights and uses these weights to weight the values, creating an output that is a weighted combination of the relevant input information.
This process allows the model to “pay attention” to the most relevant parts of the input for each part of the output.
This is especially useful in tasks such as translation, where the relevance of different input words may vary depending on the part of the sentence being translated.
## Softmax Activation Function

The softmax function is an activation function widely used in neural networks, especially in classification scenarios, where it is important to transform raw output values, known as logits, into probabilities that sum to 1.
Below is the code for the softmax function, with comments on each line explaining how it works:

```python
# Softmax activation function
def softmax(x):

    # Calculates the exponential of each input element, adjusted by the maximum value in the input
    # to avoid numerical overflow
    e_x = np.exp(x - np.max(x))

    # Divides each exponential by the sum of exponentials along the last axis (axis=-1)
    # reshape(-1, 1) ensures that the division is performed correctly in a multidimensional context
    return e_x / e_x.sum(axis=-1).reshape(-1, 1)
```
## Scaled Dot Product

The `scaled_dot_product_attention()` function is a component of the attention mechanism in Transformer models.
It calculates attention between sets of queries (Q), keys (K), and values (V).
Essentially, this function allows the model to assign different levels of importance to different parts of the input, a key aspect that makes Transformer models particularly effective for NLP tasks and other sequential tasks.

```python
# Defines the function to calculate scaled dot-product attention
def scaled_dot_product_attention(Q, K, V):

    # Calculates the dot product between Q and the transpose of K
    matmul_qk = np.dot(Q, K.T)

    # Gets the dimension of the key vectors
    depth = K.shape[-1]

    # Scales the logits by dividing them by the square root of the depth
    logits = matmul_qk / np.sqrt(depth)

    # Applies the softmax function to obtain the attention weights
    attention_weights = softmax(logits)

    # Multiplies the attention weights by the values V to obtain the final output
    output = np.dot(attention_weights, V)

    # Returns the weighted output
    return output
```
## Model Output with Linear Operation and Softmax

The `linear_and_softmax()` function is a combination of a linear layer followed by a softmax function, commonly used in deep learning models, especially in classification tasks.

```python
# Defines the function that applies a linear transformation followed by softmax
def linear_and_softmax(input):

    # Initializes a weight matrix with normally distributed random values
    # This matrix connects each model dimension (dim_model) to each vocabulary word (vocab_size)
    weights = np.random.randn(dim_model, vocab_size)

    # Performs the linear operation, or dot product, between the input and the weight matrix
    # The result, logits, is a vector that represents the input transformed into a higher-dimensional space
    logits = np.dot(input, weights)

    # Applies the softmax function to the logits
    # This transforms the logits into a probability vector, where all elements sum to 1
    return softmax(logits)
```
## Building the Final Model

```python
# Final model function
def transformer_model(input):

    # Embedding
    embedded_input = embedding(input, vocab_size, dim_model)

    # Attention Mechanism
    attention_output = scaled_dot_product_attention(embedded_input, embedded_input, embedded_input)

    # Linear layer and softmax
    output_probabilities = linear_and_softmax(attention_output)

    # Choosing the indices with the highest probability
    output_indices = np.argmax(output_probabilities, axis=-1)

    return output_indices
```
